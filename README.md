# SHOYEB Live Karaoke PWA

Upload all files/folders to the root of a GitHub Pages repository.

IMPORTANT: microphone access requires the HTTPS GitHub Pages URL. Opening index.html directly from a downloaded ZIP cannot provide normal microphone/PWA access on Android browsers.

1. Deploy to GitHub Pages.
2. Open the HTTPS Pages URL once while online.
3. Allow microphone permission when START MIC is pressed.
4. Install the PWA if desired.
5. After the app shell is cached, it can open offline. Local audio files can be selected on the device; internet streaming cannot work offline.
6. Headphones are strongly recommended.
